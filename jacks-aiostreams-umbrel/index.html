Jack's AIOStreams (Umbrel)

This Umbrel app runs AIOStreams for FilmBox. Umbrel's /app/<id>/ path prefix breaks some addons, so we expose AIOStreams on a dedicated port and show the URLs here.

Local (LAN)

UI: http://umbrel.local:3010

Manifest: http://umbrel.local:3010/manifest.json

For FilmBox VPS (via Tailscale)

UI: http://<UMBREL_TAILSCALE_IP>:3010

Manifest: http://<UMBREL_TAILSCALE_IP>:3010/manifest.json
